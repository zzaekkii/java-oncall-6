# java-oncall

# 📌 요구사항 요약
주어진 근무표를 기준으로 평일/휴일 근무가 연속되지 않게 근무표 생성
<br/>

#### 플로우
1. 근무표를 만들 달과 시작 요일을 입력 받음
2. 평일 근무표를 입력 받음
3. 휴일 근무표를 입력 받음
4. 근무표 생성
5. 근무표 출력

## ⭐ 특이 사항
- [ ] 근무 순번상 연속될 경우 다음 근무자와 변경
- [ ] 닉네임은 중복 불가, 최대 5자까지 허용
- [ ] 근무자는 5명 이상, 35명 이하
- [ ] 주어진 법정 공휴일을 휴일로 등록
- [ ] 2월은 28일까지로 고정
- [ ] 근무표 출력 시, 평일이었던 법정공휴일은 요일 뒤에 `(휴일)`로 표시 
<br/>

- [x] `Oncall` 클래스 생성 (날짜, 근무자)
- [x] `Oncalls` 클래스 생성 (월, 시작 요일, 근무 리스트)  - 근무자가 해당 날짜에 근무 가능한지 판단 및 해당 날짜 근무 생성(여기 책임 같은데)
