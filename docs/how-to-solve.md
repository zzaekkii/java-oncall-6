### 미션 해결 전략 
#### 1. 본인이 이해하고 구현한 내용에 기반해 '다른 근무자와 순서를 바꿔야 하는 경우'를 자신만의 예시를 들어 설명하세요. (필수)
```
수 목(휴일) 금 토 일 월 화(휴일)
```
예를 들어 이런 일주일로 시작하는 달이 있을 때,

```
평일: A B C D E
휴일: A B C D E
```
근무표가 이렇게 5인으로 구성되어 있다면,
```
[평일] 수: A
[휴일] 목: B (A -> B)
[평일] 금: C (B -> C)
[휴일] 토: A (B와 바꾼 결과)
[휴일] 일: C (B와 바꾼 결과)
[평일] 월: B (C와 바꾼 결과)
[휴일] 화: D
```
이렇게 중간자인 B가 앞 타임 휴일 근무자 A와 변경하고,
바뀐 근무로 인해 본인의 평일 근무를 뒤 타임 평일 근무자 C와 변경하게 됩니다.



#### 2. 요구사항에서 제시한 앞의 날짜부터 순서를 변경하는 방법 외에 다른 방법이 있다면 어떤 방식이 있는지, 이 방법은 기존에 제시된 방식과 비교해 어떤 차이가 있는지 설명하세요. (선택)
앞의 날짜부터 변경하는 방법이긴 한데 지금 방식과 약간 다른 버전도 가능합니다.
그냥 근무 순서 변경이 있을 때마다 근무표의 순서 자체를 바꿔버리는 거죠.
기존에 임시로 당시에만 바꾸고 체제를 유지하는 방식으로는 특정 달에 남들보다 근무를 이틀 가량 더 서는 상황이 생길 수 있습니다.
예를 들어 5인 체제인 상황에서 2월에 법정공휴일이 많이 섞인 경우
```
일 월 화(휴일) 수 목(휴일) 금 토
일 월 화(휴일) 수(휴일) 목(휴일) 금(휴일) 토
일 월 화 수 목 금 토
일 월 화 수(휴일) 목(휴일) 금(휴일) 토
```
같은 상황이라면 A가 7번, B가 6번, C-E는 5번 근무를 서게 되는데,

만약 근무 변경이 생길 때마다 실제 순서를 바꿔버리게 된다면,
(아직 추상적인 생각이기도 하고, 시간상 나중에 작성하겠습니다)
